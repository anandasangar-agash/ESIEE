Exercie 1 - Agenda

  1. La classe Event permet d'initialiser un nouveau événement avec la date, l'occupation et le lieu et la classe Agenda permet d'ajouter l'événement dans la liste.

    La fonction render permet d'afficher la vue de l'agenda avec tous les événements et replaceView permet de remplacer la vue existante par par une nouvelle vue lorsqu'on ajoute un événement.

    Les avantages de cette technique sont plus lisible et plus facile à écrire. L'inconvénient de cette technique c'est qu'il est moins performant, donc plus lent car on doit parser le String en HTML.

    La ligne e.preventDefault() sert à empêcher le comportement par défaut du formulaire.
  2. Les objets JSON bruts peuvent avoir des champs en plus ou en moins, ou mal nommés. C'est pour ça qu'avec Event, on vérifie bien si on a bien les champs qu'on attend (id, when, what, where).
  3. On doit ajouter la méthode removeEvent dans la classe Agenda.
  4. Dans la classe Agenda, on va ajouter un champ editingId qui vaut null au départ et lorsqu'on va cliquer sur le bouton edit d'un Event, on affecte son id et on affiche le formulaire pour éditer.
  5. Dans la classe Agenda, on ajoute un Set appelé pendingIds. Avant l'appel au serveur on y ajoute l'id, on le retire quand on a reçu la réponse.
    Dans la méthode vue, on va vérifier pour chaque Event, si son id se trouve dans pendingIds, si c'est le cas on désactive les boutons de cet Event jusqu'à qu'on reçoit la réponse.
